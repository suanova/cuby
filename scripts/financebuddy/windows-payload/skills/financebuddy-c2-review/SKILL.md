# 主板 C2 披露檢查

用戶要檢查整份ESG有無遺漏時，使用完整C2流程。首頁「C2 披露檢查」與「一致性審閱」各有結果及追問紀錄，共用項目文件版本，單份中文或英文ESG即可開始。年報可補交；不要求四份PDF。舊12項Scope1/2只是保留的獨立示範，不是完整檢查入口。

1. 先 `manage_finance_project(operation="list")` 找用戶指定項目／版本；已有文件不要求再上載。原件及每版審閱固定SHA，不修改共享知識庫或正式PDF。
2. 用指定版本 `manage_finance_project(operation="build",project_id=...,version_id=...,kind="c2",comparisons=["internal","restatement"])` 建立副本，或沿用用戶選定的已有run。不得找本年乾淨版對答案。WeKnora只供授權舊年度對照。
3. `start_c2_disclosure_review(run_id=...,profile={period_start:"YYYY-MM-DD",period_end:"YYYY-MM-DD",part_d_mandatory:"unknown",primary_esg_slot:"esg_zh"或"esg_en"})` 啟動背景核對。起訖日依用戶輸入及報告確認；清單適用2025年起財年，不能拿新版審舊年度。大型股資格及歷史強制適用狀態未確認用unknown；yes/no須有用戶或可靠來源確認，2026年起才按資格轉換Part D義務。
4. 同時有中英ESG必須選primary_esg_slot作待審稿，不能用另一語言補足本稿缺漏。沒有年報或刊載證據時，相關項目列待補，不阻塞其餘審閱。
5. 用 `read_consistency_review(run_id)` 看精簡狀態，`full=true`供Reader。running時不重複啟動或頻繁輪詢。失敗可用原profile繼續；完成批次及接受／忽略紀錄保留。換文件、規則或適用設定須建立新審閱。

長報告按C2七組工作分批，使用所選語言的ESG及對應年報全文；另一語言只留作獨立一致性審閱。如只有另一語言的年報，可用該份支援明確交叉引用，但不可用另一語言ESG補本稿缺漏。氣候計劃比較才加入去年同語ESG。輸入保留每頁所有實際文字區塊、短標題、單位及真實頁碼，將長區塊分成連續編號引文；不重複傳送全文、引文和嵌套稽核紀錄，也不刪頁或以摘要冒充全文。`compliance.source_plan`記錄實際主審範圍。預算不足代表本批未開始處理，不是報告錯誤或引用錯誤；原profile繼續現有run，不要求用戶重新上載。

後台先為固定PDF的原文片段編號，模型只選片段編號，程式還原原文及實際頁碼後再逐字驗證。驗證失敗只重試該次未通過的項目；每批仍須完成初審及獨立覆核才發布。這是審閱流程的狀態，不是報告的合規判斷。遇到引用失敗，直接說「模型引文未能對上報告原頁，相關項目尚未有結論」，不要把未完成項目當作披露缺失或說「被系統攔住」。

清單 `cuby/config/c2-full-catalog.json` 包含第1–41段及Part C全部一般披露／KPI的89個單元、148項拆解，分7批。已刪除A1.2、A4一般披露及A4.1另列，不算現行遺漏。定義、義務架構及閱讀指引登記為context，不要求公司逐字重述。每項有規則原文及實際PDF頁碼。完整規則及附註與完整報告文字交給模型；第一輪及獨立覆核都須處理每個rule_id。逐字驗證引用，索引、標題或舊報告不等於本稿披露證據。

區分強制、Scope1/2強制、不遵守就解釋、建議披露及待確認分類。保留條件、where appropriate、if any、否定陳述、整合披露及豁免條件。Scope3專屬方法不能支持Scope1/2。公司主張豁免不等於已批准；不能把建議披露當硬性義務、把通用政策當所有細項滿足。

結果包括：有披露證據、披露未完整、未找到披露、與條款有直接衝突、有解釋待核、有不適用依據、適用性待確認、需補外部資料、尚未核對。未找到不直接稱違規；只有直接相反原文才標衝突。缺漏附已查範圍及所需補件。公開披露與內部台帳真實性分開，不要求企業公開條文未要求的全部底稿。

追問先 `read_consistency_issue(run_id,check_id)`，取得該項要求、缺少要素、條款引用及相關原頁。`read_c2_rule_page(run_id,page)`顯示固定守則原頁，報告原頁用 `read_consistency_page`。沒有可改原句只提供需補資料及核實建議，不抄守則編造公司已實施政策。已有原句才用 `edit_consistency_draft`產生改寫；接受、忽略及事實確認由人類操作。

回覆自然、直接，先用一兩句講具體問題及需補甚麼。已公開不等於全通過；已掃描不等於圖表位置、原始數據或法律合規全部核實。規則版本未確認／已變更、OCR或圖表限制及缺年報等均明示，不能稱最新全C2已通過。

## 保留的舊示範

只有用戶明確要「12項Scope1/2示範」或舊TEST ONLY錯漏測試時，才用 `prepare_c2_review`及 `finalize_c2_review`，依回傳八項判讀及四項自動檢查完成舊底稿。固定FY2025/26原件版式；舊結果不能當148項結果。測試副本逐頁標記TEST ONLY，不能讀控制組答案幫自己過測試。
